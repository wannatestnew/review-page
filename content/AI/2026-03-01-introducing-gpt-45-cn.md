# 介绍 GPT-4.5

我们很高兴宣布 GPT-4.5，这是我们最新、最强大的模型。

## 主要改进

### 1. 更强的推理能力
GPT-4.5 在复杂推理任务上表现出色，能够处理需要多步骤思考的问题。

### 2. 更好的世界知识
通过扩大训练数据集，GPT-4.5 拥有更广泛的世界知识，能够回答更多领域的问题。

### 3. 减少幻觉
GPT-4.5 显著减少了"幻觉"（即生成虚假信息）的情况，提供更可靠的回答。

### 4. 更自然的对话
模型在对话中表现更加自然，能够更好地理解上下文和用户意图。

## 技术规格

| 特性 | 详情 |
|------|------|
| 参数规模 | 未公开 |
| 上下文窗口 | 128K tokens |
| 训练数据 | 截至 2026 年 |
| 多模态 | 支持文本和图像 |

## 可用性

GPT-4.5 现已通过 OpenAI API 向开发者提供，并将在 ChatGPT 中逐步推出。
