# 介绍 Claude 3.5 Sonnet

标题: 介绍 Claude 3.5 Sonnet

URL 来源: https://www.anthropic.com/research/claude-3-5-sonnet

Markdown 内容:
![图像 1: Claude 头部插图](https://www.anthropic.com/_next/image?url=https%3A%2F%2Fwww-cdn.anthropic.com%2Fimages%2F4zrzovbb%2Fwebsite%2F4e78f69ef8d4186fb5691714abe36224483d91b0-2880x1620.png&w=3840&q=75)

*   更新

消费者条款和隐私政策

2025年8月28日

今天,我们推出了 Claude 3.5 Sonnet - 即将推出的 Claude 3.5 模型系列的首次发布。Claude 3.5 Sonnet 将行业智能水平提升到新高度,在广泛的评估中超越了竞争对手模型和 Claude 3 Opus,同时保持了中端模型 Claude 3 Sonnet 的速度和成本。

Claude 3.5 Sonnet 现已免费提供在 Claude.ai 和 Claude iOS 应用程序上,而 Claude Pro 和团队计划订阅用户可以访问更高的速率限制。它也可通过 Anthropic [API](https://docs.anthropic.com/en/home)、[Amazon Bedrock](https://aws.amazon.com/blogs/aws/anthropics-claude-3-5-sonnet-model-now-available-in-amazon-bedrock-the-most-intelligent-claude-model-yet/) 和 [Google Cloud's Vertex AI](https://cloud.google.com/blog/products/ai-machine-learning/announcing-anthropics-claude-3-5-sonnet-on-vertex-ai-providing-more-choice-for-enterprises) 获得。该模型的输入令牌成本为每百万 3 美元,输出令牌成本为每百万 15 美元,上下文窗口为 200K 个令牌。

![图像 2: Claude 模型系列](https://www.anthropic.com/_next/image?url=https%3A%2F%2Fwww-cdn.anthropic.com%2Fimages%2F4zrzovbb%2Fwebsite%2F1f044104447e9db6b22db3a06e45d114f50f274e-2200x1174.png&w=3840&q=75)

2倍速度的前沿智能
-------------------------------------

Claude 3.5 Sonnet 在研究生级推理 (GPQA)、本科级知识 (MMLU) 和编码能力 (HumanEval) 方面创下了新的行业基准。它在理解细微差别、幽默和复杂指令方面有显著提升,并擅长以自然、贴近的语气撰写高质量内容。

Claude 3.5 Sonnet 的运行速度是 Claude 3 Opus 的两倍。这种性能提升,加上具有成本效益的定价,使 Claude 3.5 Sonnet 非常适合复杂任务,如上下文敏感的客户支持和协调多步工作流程。

在一项[内部代理编码评估](https://www-cdn.anthropic.com/fed9cc193a14b84131812372d8d5857f8f304c52/Model_Card_Claude_3_Addendum.pdf)中,Claude 3.5 Sonnet 解决了 64% 的问题,而 Claude 3 Opus 只解决了 38%。我们的评估测试了模型修复错误或根据自然语言描述向开源代码库添加功能的能力。在得到指示并[提供相关工具](https://www.anthropic.com/news/tool-use-ga)后,Claude 3.5 Sonnet 可以独立编写、编辑和执行代码,具有复杂的推理和故障排除能力。它能轻松处理代码翻译,这使其特别适合于更新遗留应用程序和迁移代码库。

![图像 3: Claude 3.5 Sonnet 基准测试](https://www.anthropic.com/_next/image?url=https%3A%2F%2Fwww-cdn.anthropic.com%2Fimages%2F4zrzovbb%2Fwebsite%2Fcf2c754458e9102b7334731fb18a965bfeb7ad08-2200x1894.png&w=3840&q=75)

最先进的视觉能力
-----------------------

Claude 3.5 Sonnet 是我们迄今为止最强大的视觉模型,在标准视觉基准测试中超越了 Claude 3 Opus。这些质的飞跃最明显地体现在需要视觉推理的任务中,如解释图表和图形。Claude 3.5 Sonnet 还可以准确地从不完美的图像中转录文本 - 这是零售、物流和金融服务等行业的核心能力,在这些行业中,AI 可能从图像、图形或插图中获取比纯文本更多的洞见。

![图像 4: Claude 3.5 Sonnet 视觉评估](https://www.anthropic.com/_next/image?url=https%3A%2F%2Fwww-cdn.anthropic.com%2Fimages%2F4zrzovbb%2Fwebsite%2Fcaff3d60763b27b59fe33e4ae984530f0dba4ddb-2200x1110.png&w=3840&q=75)

Artifacts - 使用 Claude 的新方式
---------------------------------

今天,我们还在 Claude.ai 上推出了 Artifacts,这是一项新功能,可以扩展用户与 Claude 的交互方式。当用户要求 Claude 生成代码片段、文本文档或网站设计等内容时,这些 Artifacts 会出现在对话窗口旁边的专用窗口中。这创造了一个动态的工作空间,用户可以在其中查看、编辑和构建 Claude 的创作,seamlessly 将 AI 生成的内容集成到他们的项目和工作流中。

这个预览功能标志着 Claude 从对话式 AI 向协作工作环境的演变。这只是 Claude.ai 更广泛愿景的开始,它很快将扩展到支持团队协作。在不久的将来,团队 - 最终是整个组织 - 将能够在一个共享空间中安全地集中他们的知识、文档和正在进行的工作,而 Claude 将充当按需的团队成员。

对安全性和隐私的承诺
--------------------------------

我们的模型经过了严格的测试,并经过培训以减少误用。尽管 Claude 3.5 Sonnet 的智能水平有了飞跃,但我们的红队评估结果表明,Claude 3.5 Sonnet 仍然处于 [ASL-2](https://www.anthropic.com/news/anthropics-responsible-scaling-policy) 级别。更多详细信息可以在[模型卡补充](https://www-cdn.anthropic.com/fed9cc193a14b84131812372d8d5857f8f304c52/Model_Card_Claude_3_Addendum.pdf)中找到。

作为我们对安全性和透明度的承诺的一部分,我们已经与外部专家合作,测试和完善了这个最新模型中的安全机制。我们最近将 Claude 3.5 Sonnet 提供给英国人工智能安全研究所(UK AISI)进行部署前安全评估。UK AISI 完成了 3.5 Sonnet 的测试,并根据美英两国 AI 安全研究所之间的谅解备忘录与美国 AI 安全研究所(US AISI)分享了测试结果,这种合作关系是[今年早些时候宣布的](https://www.commerce.gov/news/press-releases/2024/04/us-and-uk-announce-partnership-science-ai-safety)。

我们已经整合了来自外部专家的政策反馈,以确保我们的评估是稳健的,并考虑了滥用行为的新趋势。这种参与帮助我们的团队扩大了我们评估 3.5 Sonnet 抵御各种滥用行为的能力。例如,我们利用[Thorn](https://www.thorn.org/)儿童安全专家的反馈来更新我们的分类器并微调我们的模型。

隐私是指导我们 AI 模型开发的核心宪法原则之一。我们不会在未经用户明确许可的情况下,在我们的生成模型上训练用户提交的数据。

即将推出
-----------

我们的目标是每隔几个月就大幅改善智能、速度和成本之间的权衡。为了完成 Claude 3.5 模型系列,我们将在今年晚些时候推出 Claude 3.5 Haiku 和 Claude 3.5 Opus。

除了致力于我们的下一代模型系列,我们还在开发新的模式和功能,以支持更多企业用例,包括与企业应用程序的集成。我们的团队还在探索诸如"记忆"等功能,它将使 Claude 能够根据用户的偏好和交互历史记住并个性化他们的体验,从而使体验更加个性化和高效。

我们一直在努力改进 Claude,并热衷于听取用户的反馈。您可以直接在产品中提供 Claude 3.5 Sonnet 的反馈,以帮助我们制定开发路线图,并改善您的体验。一如既往,我们期待看到您使用 Claude 所建立、创造和发现的内容。
